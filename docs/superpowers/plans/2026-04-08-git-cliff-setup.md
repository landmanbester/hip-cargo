# git-cliff Changelog Automation Setup

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate git-cliff for automated changelog generation, wire it into the tbump release workflow, and document conventional commit practices for contributors.

**Architecture:** git-cliff is configured via `cliff.toml` at the repo root. It reads git tags and conventional commit messages to produce a Keep a Changelog-formatted `CHANGELOG.md`. The tbump `before_commit` hooks run `git-cliff` before each release to regenerate the changelog automatically. The `hip-cargo init` templates are updated so scaffolded projects get the same setup.

**Tech Stack:** git-cliff (Rust binary, installed via cargo or pipx), tbump, GitHub Actions (git-cliff-action)

### Task 1: Create `cliff.toml` Configuration

**Files:**
- Create: `cliff.toml`

This configures git-cliff to parse conventional commits and output Keep a Changelog format. The config groups commits by type prefix (`feat:`, `fix:`, etc.), skips chore/ci/style commits from the changelog body, and uses the existing tag pattern `v*`.

- [ ] **Step 1: Create `cliff.toml`**

```toml
# git-cliff configuration for hip-cargo
# See https://git-cliff.org/docs/configuration

[changelog]
header = """# Changelog

All notable changes to hip-cargo are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).\n
"""
body = """
{%- macro remote_url() -%}
  https://github.com/{{ remote.github.owner }}/{{ remote.github.repo }}
{%- endmacro -%}

{% if version -%}
    ## [{{ version | trim_start_matches(pat="v") }}] - {{ timestamp | date(format="%Y-%m-%d") }}
{% else -%}
    ## [Unreleased]
{% endif -%}

{% for group, commits in commits | group_by(attribute="group") %}
    ### {{ group | striptags | trim }}
    {% for commit in commits %}
        - {% if commit.scope %}**{{ commit.scope }}**: {% endif %}{{ commit.message | upper_first }}\
          {% if commit.github.pr_number %} ([#{{ commit.github.pr_number }}]({{ self::remote_url() }}/pull/{{ commit.github.pr_number }})){% endif %}\
    {% endfor %}
{% endfor %}
"""
footer = """
{%- macro remote_url() -%}
  https://github.com/{{ remote.github.owner }}/{{ remote.github.repo }}
{%- endmacro -%}

{% for release in releases -%}
    {% if release.version -%}
        {% if release.previous.version -%}
            [{{ release.version | trim_start_matches(pat="v") }}]: {{ self::remote_url() }}/compare/{{ release.previous.version }}...{{ release.version }}
        {% else -%}
            [{{ release.version | trim_start_matches(pat="v") }}]: {{ self::remote_url() }}/releases/tag/{{ release.version }}
        {% endif -%}
    {% else -%}
        {% if release.previous.version -%}
            [Unreleased]: {{ self::remote_url() }}/compare/{{ release.previous.version }}...HEAD
        {% endif -%}
    {% endif -%}
{% endfor %}
"""
trim = true

[git]
conventional_commits = true
filter_unconventional = false
split_commits = false
commit_parsers = [
    { message = "^feat", group = "Added" },
    { message = "^fix", group = "Fixed" },
    { message = "^refactor", group = "Changed" },
    { message = "^perf", group = "Changed" },
    { message = "^docs", group = "Documentation" },
    { message = "^deps", group = "Dependencies" },
    { message = "^chore: update cab definitions", skip = true },
    { message = "^chore", group = "Miscellaneous" },
    { message = "^ci", group = "CI" },
    { message = "^style", skip = true },
    { message = "^test", group = "Testing" },
    { message = "^Bump version", skip = true },
    { message = "^Merge", skip = true },
    { message = "^manually revert", group = "Fixed" },
    # Catch-all for non-conventional commits
    { message = ".*", group = "Other" },
]
protect_breaking_commits = false
filter_commits = false
tag_pattern = "v[0-9].*"
skip_tags = ""
ignore_tags = ""
topo_order = false
sort_commits = "newest"

[remote.github]
owner = "landmanbester"
repo = "hip-cargo"
```

- [ ] **Step 1: Add commit convention section to README.md**

Insert the following **after** the "Manual Code Quality Checks" section (after line 489) and **before** the "Contributing Workflow" section:

```markdown
### Commit Message Convention

This project uses [Conventional Commits](https://www.conventionalcommits.org/) to enable automated changelog generation via [git-cliff](https://git-cliff.org/).

Every commit message should follow this format:

```
<type>: <description>

[optional body]
```

**Types:**

| Type | When to use | Changelog section |
|------|------------|-------------------|
| `feat` | New feature or capability | Added |
| `fix` | Bug fix | Fixed |
| `refactor` | Code change that neither fixes a bug nor adds a feature | Changed |
| `perf` | Performance improvement | Changed |
| `docs` | Documentation only | Documentation |
| `test` | Adding or updating tests | Testing |
| `ci` | CI/CD changes | CI |
| `deps` | Dependency updates | Dependencies |
| `chore` | Maintenance tasks (cab regeneration, formatting) | Miscellaneous |

**Examples:**

```bash
git commit -m "feat: add support for MS dtype in type inference"
git commit -m "fix: handle empty docstrings in introspector"
git commit -m "refactor: simplify generate_cabs output formatting"
git commit -m "docs: add container fallback section to README"
git commit -m "test: add roundtrip test for List types"
```

**Scoped commits** (optional): Use parentheses to specify the affected component:

```bash
git commit -m "feat(init): add --license-type option for BSD-3-Clause"
git commit -m "fix(runner): resolve volume mount for symlinked paths"
```
```
